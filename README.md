
# Healthcare Data Analysis using Python

## Project Overview
This project analyzes a sample healthcare dataset using Python and Pandas.

## Objectives
- Calculate average patient age.
- Calculate average systolic blood pressure.
- Analyze disease categories.
- Filter patients with blood pressure greater than or equal to 140.
- Export the dataset to a CSV file.

## Technologies Used
- Python
- Pandas
- Google Colab

## Files
- `healthcare_analysis.py` — Python analysis code.
- `healthcare_analysis.csv` — Healthcare dataset.

## Module 2: Data Analysis with Python

This module focuses on exploring, cleaning, and analyzing a sample healthcare dataset using Python.

### Objectives
- Import CSV datasets using Pandas.
- Explore dataset shape, column names, and data types.
- Generate statistical summaries.
